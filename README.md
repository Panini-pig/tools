# 帕尼尼工具箱

`tools.panini-pigs.cn` 的静态网站发布仓库。仓库根目录即 Cloudflare Pages 的发布目录，无需构建命令。

站点支持深色 / 浅色 / 跟随系统三种主题，首次访问默认深色，选择保存在浏览器本地。

- `/`：工具箱首页，混合展示在线工具、桌面软件和浏览器插件，可按分类筛选。
- `/image-compressor/`：本地图片压缩工具。
- `/paste-helper/`：浏览器插件「剪贴板键入助手」的详情与安装页。主线是 Edge 加载项商店，ZIP 只作离线备用。
- `/qq-space-backup/`：桌面工具详情/下载页模板。首页的 QQ空间备份助手卡片直接跳转独立站，不经此页。
- 抖音聊天记录备份工具：首页卡片直接跳转 `https://panini-pigs.cn/`，本站不提供详情或下载页。
- `DESIGN.md`：视觉与组件规范。文中的 `main/`、`build.ps1` 等路径指本地源项目；本仓库是构建产物。

页面使用相对路径，既能部署在域名根目录，也能部署在子路径。图片压缩在浏览器本地完成；本仓库不存储 QQ空间备份助手的安装包。
